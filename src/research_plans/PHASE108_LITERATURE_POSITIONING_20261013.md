# Phase108：文献定位与最小对照缺口

## 做什么

查清当前“冻结网络分数＋浅层影像读出”相对已有工作的真实差异，再决定下一条研究分枝。**本轮只检索与审读；零训练、拟合、前向、校准或新评价。**不为得到正结果继续搜索波段或读出参数。

## 1．固定审读入口

优先读以下一手材料，最多另补2篇直接相近工作；只获得摘要时明确标记，不据此断言实现细节。

| 入口 | 核验重点 |
|---|---|
| [Cloud-Adapter](https://arxiv.org/abs/2411.13127) | 当前Source的原始方法、训练数据、已有消融及实际可继承贡献 |
| [Comparison of cloud detection algorithms for Sentinel-2 imagery](https://ntrs.nasa.gov/api/citations/20210014061/downloads/Masek_Comparison_Cloud_Detection.pdf) | 多算法输出的stacking，当前浅层组合与其异同 |
| [CloudS2Mask](https://doi.org/10.1016/j.rse.2024.114122) | 强云影基线、训练数据、PixBox评价与公开推理条件 |
| [SEnSeI](https://doi.org/10.1109/TGRS.2021.3128280) | 光谱编码与传感器泛化；不要把多波段使用本身当创新 |
| [Fmask 5作者说明](https://shi-eo.github.io/publication/2025-fmask5)及其正式论文／作者代码 | 物理规则与机器学习结合；核验版本及出版状态，不能把旧网页状态当最新事实 |
| [CMIX原文](https://ntrs.nasa.gov/api/citations/20220006382/downloads/rse-2022-112990.pdf) | 云影任务映射、PixBox采样与公平评价限制 |

检索覆盖截至执行日可访问工作，记录日期、DOI、正式／预印本状态及原文位置。不得只用二手总结、排行榜或搜索摘要替代审读。作者代码作为实现证据，不能用当前master证明论文当年设置。

## 2．交付一张方法与证据对照表

每篇记录：目标类是否包含云影、输入波段／辅助数据、网络与浅层读出关系、训练与适配监督、是否使用模型概率作为特征、校准方法、评价单位、场景隔离、参考数据、成本证据及局限。

另列公开权重／代码／许可证、推理输入、所需下载量、原训练数据与本项目评价池的已知重叠。无完整清单写unknown；同一数据集曾用于该基线训练时，不能称该数据集上的比较为外部泛化。

从中只选**最多2个最有必要的强对照**，说明选它们能排除什么解释，以及当前六波段／格网能否满足输入。只估算复现条件，不安装依赖、不下载权重、不运行对照或追加波段。

## 3．用现有证据约束主张

只引用已验收结果，不重算区间：

- Phase66：原冻结候选与当时预定主要比较的支持，不能转给新模型。
- Phase105：G7−G6在PixBox采样点上的预定AP增量；同时保留冻结工作点误报增加。
- Phase106：Source＋NIR/SWIR相对Source的事后增量。
- Phase107：PixBox同容量S−R区间跨零，光谱特异性不确定，不能写等效。
- Phase72、85、94—100：原失败分枝、种子不稳定、误报迁移及尾部失效继续保留。

明确区分“组合有效”“特定输入更有价值”“机制获识别”“新算法贡献”四类主张。找到相近既有方法时如实指出；没找到不等于证明首次。文献报告数值不能直接与本项目不同支持上的AP拼表排名。

## 4．最后只给一个下一问题

写不超过一页`NEXT_QUESTION.md`，包含：

1. 当前最可辩护的贡献表述及明确不能声称的部分；
2. 一个仍未解决、且与文献有实际区别的可证伪问题；
3. 最小实验／强对照、需要新增什么证据、成本上限与停止条件草案；
4. 已暴露池只能探索；若需要新独立支持，明确目前是否具备。

若只能支持已有stacking思路在本任务上的实证应用，如实写出，不虚构机制或承诺TGRS录用。若现有条件不足以检验新的方法主张，也可以建议结束该方法路线并转向证据充分的实证问题，不用一次新浅层拟合掩盖缺口。
