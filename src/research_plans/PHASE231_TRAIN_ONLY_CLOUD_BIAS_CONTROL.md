# Phase231：训练侧单偏置校准对照

## 做什么

固定模型，只拟合一个全局Cloud偏置，检查Phase230观察到的漏云能否用简单校准减轻，以及误报／云影代价。**不是新网络方法，不做逐景校准，不搜索多个配方。**

需要拟合偏置的模型仅3个：Source、L8-C21701、L8-C21702；C仍为原4000步末头、α=0.25。模型与分数定义沿用230。SPARCS两个本池头只作230未校准历史参照，不新增拟合。

## 1．固定数据与前向

- 校准：原SPARCS **60个target_train场景**，清单见 `phase231_frozen_20261026/CALIBRATION_INPUTS.json`。它们曾用于训练SPARCS专用头，不是独立新校准集。当前Source／L8头将额外使用这些SPARCS标签，必须披露，不能继续称为无SPARCS监督的跨域迁移。
- 评价：原230的SPARCS **10景validation分数／标签缓存**，只做CPU读取；不新增validation前向，不读任何test、L8或源域影像／标签。
- 对校准60景按230**评价加载方式**：整图resize512、无随机裁剪／增强、原三父类映射；不复用训练增强后的输入SHA作为文件SHA。开始前核对原训练身份及与val场景互斥，封存实际输入文件SHA。
- 3模型×60景＝180次前向，按230提取三类分数p。只读已有模型和数据，不下载、不重训，不改α、骨干／buffer或网络参数。
- 只保存校准所需d与标签／场景小型缓存，不保存全骨干特征。处理标签与分数的几何必须和230一致。

## 2．唯一拟合规则

每个模型独立拟合一个标量b。校准任务仅参考Cloud（y=1）vs Surface（y=0），Shadow与ignore不参与损失；有Cloud或Surface像元的场景都参与，不因缺Cloud删除负类场景。

```text
d = log(max(pCloud,1e-12)) - log(max(pSurface,1e-12))
L(b) = mean_scene mean_valid_pixels [ logaddexp(0,d+b) - y*(d+b) ]
```

场景等权，场景内有效像元等权；不另做正负类平衡、不抽样。b固定限制为[-5,5]，唯一解法为导数单调二分：

```text
g(b) = mean_scene mean_valid_pixels [ sigmoid(d+b) - y ]
若g(-5)>=0，取b=-5；若g(5)<=0，取b=5；否则二分60次取区间中点。
```

使用float64稳定实现。报告校准场景数／支持、b、L(0)、L(b)、g(b)及是否触及边界。触边也不扩区间、不换损失或正则。没有两类总支持或数值异常就报失败，不自动另找规则。

**先封存3个b及拟合输入／代码SHA，再运行任何validation校准分析。** 不看val选择偏置方向或大小；训练侧拟合出的b可能无法改善val，照样提交。

## 3．冻结后怎样评价

对230原val缓存，同时保留原始p与偏置后三类决策：

```text
qSurface = pSurface
qCloud   = exp(b) * pCloud
qShadow  = pShadow
pred_cal = argmax(qSurface,qCloud,qShadow)  # 原父类顺序及ties规则
```

可归一化q，但不额外softmax。b=0必须精确复现230预测与混淆。二类Cloud／Surface诊断仍用d+b>0， ties归Surface。

- 校准前后逐景／池化三类mIoU、Cloud召回、Surface→Cloud FPR、Shadow召回、非Shadow→Shadow FPR；同时保留场景平均与其有效场景数。
- 主排序指标使用d与d+b的Cloud／Surface AUC、AP；全局常数平移应保持排序，核对数值不变量。排序不变不代表实际决策无代价。
- 交六向净错误计数差；如保存校准前后逐像元预测，另交直接转移表并明确与净变化的区别。
- 仅算预定结果，不扫阈值、偏置网格，不用val选最大收益点，不额外计算oracle恢复曲线或新显著性区间。

## 5．预算和收口

最多 **220次完整输入前向、GPU30分钟**；180次主体，其余仅固定门检／重复与构建探测。CPU拟合及分析最多60分钟、CPU8GiB、GPU20GiB、新增输出512MiB。校准缓存可保存float32的d，拟合时转float64；不要缓存全三通道后再复制多份。

零网络参数更新，新增仅3个标量；不读取校准之外的训练像元。缺文件／身份不符／超预算即报告，不补训练、不换校准池、不追加搜索。独立CPU复核偏置求解、全部val指标、b=0与排序不变量；校准输入与val缓存访问先后需留回执。

结论只回答：简单的训练侧全局校准实际恢复了什么、付出了什么、还有哪些局部损伤。观察性修正不等于证明物理成因；不据此宣称新算法或自动启动修复训练。
