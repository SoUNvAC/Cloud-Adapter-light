## 3．唯一新公式

冻结教师eval；对原512×512共同几何支持，置信度及原G权重严格复现219：全图教师最大semantic-softmax概率稳定排序，高半1.5、低半0.5，相等时行优先。

```text
t_i = 原Source正式语义路径的三类argmax
g_i = 原G权重，取0.5或1.5

对每张图中每个存在的教师预测类c：
    I_c = {i: t_i=c}
    m_c = mean(g_i, i in I_c)
    n_i = g_i / m_c
    p[I_c] = 按固定类内置换重排n[I_c]

L_N = mean_i(n_i * KL(Source_i || Student_i))
L_P = mean_i(p_i * KL(Source_i || Student_i))
总loss = 原目标监督loss + 1 * L_N或L_P
```

类别顺序Surface／Cloud／Shadow。不用参考类别、学生预测或已知损伤ROI生成权重。空类跳过，不补像元；单像元类及类内g恒定时归一化后均为1，P与N可相同，照实记录。

用CPU float64计算m_c及归一化后转float32；不加epsilon、不clip、不再全图重标定，m_c必在[0.5,1.5]。权重在[1/3,3]内，每个存在类平均约1，全图平均约1；CPU双精度复核float32保存值，绝对容差1e-6。N／P每类权重直方图与权重和一致；不声称实际KL值或梯度范数相同。

每图每类的局部PCG64种子：`int.from_bytes(SHA256('phase221|' + 官方source_sample_id + '|' + str(c))[:8], 'big')`。在该类行优先索引列表上生成一次permutation，两个训练seed共用，重复回放不重抽；锁NumPy版本，不调用全局RNG。保存g、教师预测类、N／P权重及类内置换SHA。优先复用219置信度／G缓存并验证；新增教师预测类必须按219预计算runtime取得。

门检零更新：初始head一致、初始KL近0，显式小数组逐像元加权KL与GPU实现一致，权重detach，梯度只到head，教师／非head不变。覆盖空类、单像元类、同置信度、全图单类等纯数组边界。门检后恢复初始化、优化器及RNG。

记录目标loss、未加权／加权KL、按教师预测类分组的权重均值与加权KL贡献、head梯度有限性。贡献大小不是因果梯度归因；不得据在线结果改λ或权重。
