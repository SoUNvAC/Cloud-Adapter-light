# Phase236：学习率／早停与插值的公平对照

## 1．本轮做什么

只训练普通目标监督C头。两目标×两seed×两学习率，共 **8次、每次4000步**；从同一次训练取早停和末步插值候选。没有KL、源回放、LoRA、新模块或新偏置拟合。当前只执行236，不自动启动237。

清单、Source身份、历史配置和支持绑定见 `phase236_frozen_20261027/`。全部新策略统一使用干净标签；234的历史L8训练仍含旧Fill处理，只作历史参照，不能用新旧差直接归因学习率。

| 项目 | 固定值 |
|---|---|
| 目标与划分 | L8 train1560裁块／18景、val963／8景、test2167／16景；SPARCS train60景、val10景、test10景 |
| seed | 21701、21702 |
| AdamW基础学习率 | 1e-4、3e-5 |
| 训练／保存步数 | 训练4000步，保存500、1000、2000、4000步头 |
| 可训练参数 | 整个decode_head，1,316,516参数；其余参数及buffer保持Source |
| 其他优化设置 | 复用217／222：batch1、weight_decay0.05、梯度裁剪1、原参数分组；LinearLR前100步从0.1倍起，之后PolyLR power0.9至4000步、eta_min0 |

早停只是从上述共同4000步调度中选择前缀checkpoint，不为500／1000／2000步重新压缩LR调度。新训练不要求与旧L8参数SHA相同。

## 2．训练前检查

1. 核对原图／标签SHA、scene互斥、Source及历史有效配置。L8复用235的train原生mask绑定，val/test复用234；native0→ignore255，128→Surface、64→Shadow、192／255→Cloud。SPARCS原0是Shadow，保留原七类映射。禁止下载、补样、变更划分或只保留有利场景。
2. L8保留原1560裁块清单，忽略Fill后再执行原几何增强；RGB、有效标签与valid mask必须同步裁剪／翻转。保留原RandomCrop512、RandomFlip0.5、PhotoMetricDistortion。SPARCS训练仍在原图随机裁512，评价仍整图resize512，不能顺带统一尺度。
3. **核验实际Mask2Former训练路径，不只检查255配置。** ignore不得成为第四类或Surface；Fill位置不得参与Hungarian匹配的掩膜代价、mask BCE／Dice及辅助层的空间监督。若默认实现仍把ignore位置作为负类监督，先做同用于全部L8训练臂的最小valid-mask修正，封存差异和测试，再训练；不改分类／掩膜损失权重、查询数或添加新损失。无法完成正确修正则报告缺口，不带病开训。
4. 对固定合成预测／GT、固定采样随机数检查：无Fill时修正实现复现原损失及梯度；有Fill时只改变无效位置的预测，损失／梯度保持不变（可微部分最大差≤1e-6），有效位置变化能改变损失。插值采样涉及的空间有效支持也须核验，不能只检查最近邻点而仍混入无效监督。保存实现SHA、匹配／采样回执。允许RGB中的Fill上下文影响有效位置，不宣称特征隔离。
5. 先统计全无效L8裁块。固定训练抽样池只排除有效像元数为0的裁块，完整保留排除清单；所有策略使用相同池，不补新裁块。若没有则保持1560。每步损失必须有限；不因loss不好临时跳步／换图。记录最终训练池及各scene曝光次数。

同目标／seed的两LR使用相同抽样顺序、增强与训练随机数种子。沿用InfiniteSampler及每步数据随机种子的历史规则，新增valid-mask所需随机数独立管理；保存4000步图像／有效标签／增强SHA。评估在独立进程进行，不能消耗训练RNG。只改LR和必需的统一Fill处理，不顺带改训练目标的图像等权为场景等权。

训练中冻结骨干为eval、头为train；每100步及保存时检查所有非头参数／buffer未变、无非头梯度。每个模型从同一Source重新初始化，优化器状态互不继承。保存4个头、优化器／调度／RNG恢复状态和逐步loss／LR，禁止因结果不好重训或增加seed。

## 3．三个策略，各9个val候选

每目标、每seed独立选择。Source是三策略共同候选，不能只允许插值回退Source。

| 策略 | Source之外的8个候选 |
|---|---|
| E：学习率＋早停 | 2个LR×4个保存步数 |
| W：末头权重插值 | 2个LR的4000步末头×α=0.25／0.5／0.75／1 |
| P：末头输出混合 | 2个LR的4000步末头×α=0.25／0.5／0.75／1 |

W只插值完整decode_head，CPU float64后转原dtype；非头均为Source。P沿用234：wrapper非负语义分数归一化为p，`(1−α)*pSource+α*p末头`，不额外softmax；P不增加网络前向。同输入在线处理，不保存全池三类分数／特征。α=0／1的端点身份须一致。

**选择：val池化三类mIoU最大，完全数值相同才按以下次序打破平局，不加epsilon。** Source优先；E再选较小步数、较小LR；W/P再选较小α、较小LR。无源侧预算条件，不按test修改选择。L8用VALID val，SPARCS用原支持，IoU沿用union>0类平均。

先封存12个选择（2目标×2seed×3策略）、完整val候选表和所有头／代码／输入SHA，再开始本轮test候选预测。历史test已暴露，这是探索性复核。禁止选早停checkpoint后再搜索α，或把全部checkpoint×α拼成更大的候选池。

## 5．计算、交付和收口

- 8×4000＝**32,000次优化器更新／训练前向，32,000次训练反传**。历史计数以每次完整输入前向记1单位，反传次数和GPU耗时另列，不冒称反传免费。
- val最大29个不同网络候选／目标：Source1＋4条训练轨迹×4保存点16＋4末头×3中间W点12。共29×(963+10)＝28,217次前向；P不增加前向。
- test最多9个不同网络候选／目标：Source1＋两seed两LR末头4＋选定E最多2＋选定W最多2，共9×(2167+10)＝19,593次。部分重合可减少，不因剩余额度新增候选。主体合计最多 **79,810前向**。
- 总上限 **85,000完整输入前向、32,000训练更新、GPU6小时**，包括门检、重复、失败；CPU分析4小时、CPU16GiB、GPU20GiB。本轮新增远端数据上限8GiB、正式交付上限2GiB；不复制Source大权重／历史全包，不保存全池分数／特征。到限交部分结果，不自动扩预算。训练与推理／CPU耗时分开列。
- 交三表、完整val候选、选择封存、逐图／逐景test混淆与预测SHA、32个头和恢复状态清单、32,000步训练账本、Fill训练修正／测试、输入／模型／代码及依赖SHA、调用／内存／耗时／失败回执。原Source复现234；独立CPU复算选择、计数、所有主要区间，检查头外状态和配对随机序列。
- 明确标签成本：18／60个训练场景与8／10个选模场景分别计入；有效标签像元、裁块／原景、训练曝光次数分开，不声称18景与60景只差场景数。

本轮只回答：同训练与候选预算下，val选择后的插值是否仍提供超出早停／LR的目标价值，以及L8负收益是否还在。若收益由合理优化解释，接受这个结果，不增加模块；若剩余差异仍在，再决定237的18景受控实验是否值得执行。未修齐的旧D/H/W／MsRE结果不进入本轮公平排名。
