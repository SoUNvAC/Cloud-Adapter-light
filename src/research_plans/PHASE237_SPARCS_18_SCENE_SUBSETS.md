# Phase237：SPARCS缩至18个训练场景的敏感性检验

## 1．执行范围

从原60个SPARCS训练场景中固定3个18景子集，各训练seed21701／21702，**仅6次、每次4000步**。学习率只用1e-4；其余训练、保存、输入与评价沿用236。没有新模块、源回放、KL、偏置拟合、额外LR或新目标域。

子集、输入及历史身份见 `phase237_frozen_20261028/`。本轮只执行237，完成后进入238结算；不得自动增加子集／seed或启动新训练。

| 项目 | 固定设置 |
|---|---|
| 子集 | SUBSET_1／2／3，各18个原train场景；对应18份原图／标签 |
| seed／LR | 21701、21702；AdamW基础LR=1e-4 |
| 训练 | batch1，4000步；保存500／1000／2000／4000步 |
| 优化与增强 | 原236的weight_decay0.05、clip1、前100步warmup及4000步Poly调度；原图随机裁512、翻转、光度增强 |
| 模型 | 同一Source；仅decode_head的1,316,516参数可训练；其他参数／buffer冻结 |
| val／test | 原SPARCS val10景、test10景；整景resize512、原七类到三类映射，原0是Shadow |

子集按不依赖标签／性能的固定规则生成：对原60个唯一scene，分别计算 `SHA256(UTF8("phase237|subset{k}|{scene}"))`，按hash再按scene升序，取前18个。k为1、2、3。清单已生成，不再抽签；允许子集间重叠，交重叠矩阵。它们不是三个独立评价数据集。

## 2．训练与60景参照

先核对原图／标签、Source／配置SHA、18景均属于原60景且与val/test互斥；不读取L8、CloudSEN或其他池像元，不下载／补样。SPARCS不存在L8 Fill定义，不套用native0忽略规则。

每子集各seed从同一Source初始化，复用236训练实现与确定性规则，仅替换训练清单、输出目录及本轮预算。每步记录scene、crop／flip／光度增强和输入／标签SHA，保留loss／LR；保存4个头及恢复状态。全无效样本、非有限loss或身份不符则停止并报告，不临时换图／改损失。每100步及保存时检查头外参数／buffer与Source一致。

**60景参照只复用236的LR=1e-4轨迹及现存val/test计数，不重训、不新前向。** 在236的val候选表中删除3e-5候选，按下一节的5候选规则重新核对选择。若选中的60景test预测未保存，报告缺口，不用另一个候选替代，也不自动扩推理。

两规模训练均为4000步、同一512裁块尺寸／调度；18景会获得更多重复曝光。分别交原图有效标签量、每景曝光／抽样裁块像元数，不把重复抽样量当独立标注量。不能把本实验解释为只改变了标签像元数，或与L8原1560裁块构成等量标签对照。

## 3．统一选模

每个子集／seed分别在同一10景val选择，下表三策略各 **5个候选**；60景参照同样为5个，不沿用236的9候选竞争。

| 策略 | 候选 |
|---|---|
| E：早停 | Source＋500／1000／2000／4000步头 |
| W：权重插值 | Source＋4000步末头的α=0.25／0.5／0.75／1 |
| P：输出混合 | Source＋同一末头的α=0.25／0.5／0.75／1 |

按val池化三类mIoU最大选择，完全相同优先Source，再取较小step／α，不加epsilon。W完整头CPU float64插值后转原dtype；P复用归一化三类语义分数算术混合，不额外softmax。非线性头的W不能由P替代，α0／1端点须一致。

先完成全部子集的val及18个选择（3子集×2seed×3策略），连同6个60景参照选择、模型／代码／输入身份封存，再启动本轮test。历史val/test已暴露，本轮为探索性复核。禁止选checkpoint后再搜α，禁止按test选子集。

test只评价Source、各训练末头、锁定E/W/P。相同模型／决策去重计费；P不增加网络前向。无需全test网格或源域保持评价。

## 5．预算与结算

- 6×4000＝**24,000优化器更新、训练前向和反传**；失败更新也占总更新预算。禁止从头重跑失败轨迹导致额外预算；可从完整恢复状态继续，已消耗更新不抵扣。
- val最多Source1＋6轨迹×4保存点24＋6末头×3中间W点18＝43个不同网络候选，430次输入前向。test最多Source1＋6末头＋6选定E＋6选定W＝19个，190次。P不新增网络调用；60景原预测只读复用。
- 主体最多24,620次完整输入前向；上限 **26,000次、24,000更新、GPU3小时**，包含门检、失败与重复。CPU分析2小时、CPU16GiB、GPU20GiB；新增远端4GiB、正式交付1GiB。不传全Source权重，不保存全池分数／骨干特征。到限交已完成项和缺口，不自动扩预算。
- 交三表、所有val候选与选择封存、逐图／逐景混淆及预测SHA、24头／恢复状态清单、训练／成本／失败账本、所有身份和重叠回执。独立CPU复核原60景选择、18景选择、主要区间、24,000步记录及头外冻结状态。Source复现236；所有结果包括失败／NA均保留。

结果若出现类似L8的退步，只说明本SPARCS设置对训练覆盖／重复曝光变化敏感，不能推出L8差异主要由标签量造成；若未出现，也不能证明数据集固有属性才是原因。无论结果方向如何，本轮后进入238结算，不按表现追加抽样。
