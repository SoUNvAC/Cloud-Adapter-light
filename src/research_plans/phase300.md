# Phase300：强云分割模型的固定伪标签适配

## 一、做什么

用 Catalogue 原 100 个 fit 相关组的无标签图像，分别训练普通残差 B 和模块 M。固定原 V4 RegNet（R4）生成一次伪标签；比较原 R4、原官方双成员 E4、R4+B-PL、R4+M-PL。

本轮完成实现、训练、评价和结果整理，回答：伪标签适配是否改善分割；是否降低云影召回；M 是否优于普通残差 B。适配不访问源样本，按 SFDA 记录。

本轮是Omni任务模型上的机制预实验。论文主线固定为**VFM骨干＋云特有偏移建模**；本轮不替代VFM实验，不以“首次云检测无源/测试时适配”为贡献。已有CNN星载云检测适配工作应列入相关工作，并按骨干、分类/像素分割、源样本访问、在线/离线和偏移建模区分。这里的普通残差B仅为模块对照，不能与研究路线名称混用。

## 二、怎么做

### 1．固定输入和模型

- 模型身份、权重 SHA、runtime 及推理实现沿用 Phase205/208；先核对实际文件，不升级依赖或重新下载权重。
- 训练清单取 Phase208 的 `12201_FIT_INPUT_LOCK.json`：保留原100组和代表产品，只提取 group/product、影像路径及成员 SHA。删除标签路径、mask SHA、类别计数、`common_valid` 等标签字段。不重新选组。
- 输入为20m B04/B03/B8A，归一化沿用原作者实现。训练有效像元仅要求三输入均有限、非零、非原始浮点填充值 `65535/10000`；无效输入填零。
- **新建纯影像加载器。** `src/tools/phase119_common.py::catalog_image(read_truth=False)` 仍读取 `masks.zip` 并用标签构造有效掩膜，不能用于本轮伪标签生成、裁剪或训练。新入口不得打开标签文件、读取标签ignore或沿用标签筛选裁剪。验证标签目录不可访问时仍能加载和训练，并交文件访问记录。
- Catalogue 原32 development组、PixBox 原16产品/10相关组仅在两个末步封存后评价；训练阶段不访问这些图像或标签。原53校准组本轮不用。
- 评价支持与ignore沿用Phase205/208，标签只由独立评价程序连接。训练纯影像支持与历史监督支持不同，分别记录。

| 策略 | 起点 | 更新范围 | 监督来源 |
|---|---|---|---|
| R4 | 原V4 RegNet | 无 | 无 |
| E4 | 原V4 RegNet+EdgeNeXt | 无 | 无 |
| B-PL | 原R4+新初始化B | 仅B，944641参数 | 固定R4伪标签 |
| M-PL | 原R4+新初始化M | 仅M，970369参数 | 与B-PL相同的固定伪标签 |

M/B结构及共同部分初始化复制规则复用 `src/tools/phase208_modules.py`、`phase207_msre_interface.py`，初始化seed=20801。不得加载监督训练后的M/B。原R4全部参数、BN和其他buffer固定，原模块始终eval；损失到新增模块的梯度保留。

### 2．生成一次伪标签

1. 按纯影像manifest生成100组完整窗口清单。R4使用原1000/300滑窗、float32、归一化和raw logits拼接规则预测；不先对窗口取argmax，不用512裁剪代替完整教师上下文。
2. 对拼接后的四类raw logits计算稳定softmax，再合并Thick/Thin概率，得到Surface/Cloud/Shadow三父类概率。保存原类别索引和映射；不使用评价分数中的 `+0.001`、clip变换。
3. 图像有效且三父类最大概率 **>=0.90** 时保留argmax伪标签，否则置ignore=255。阈值固定，不读标签确定阈值，不增加类别权重或配额。
4. 逐产品保存伪标签、最大概率、图像有效掩膜和SHA；两臂共用同一缓存。缓存固定，不刷新、不加EMA。逐产品处理，不将全部原始影像和四类logits同时留在内存。

### 3．训练两臂

- 裁剪/训练随机seed=30001。新生成1000步序列：每步均匀抽一个fit代表图像、均匀抽合法512裁剪位置，水平翻转概率0.5；图像和伪标签同步变换。两臂序列相同，不沿用旧标签筛选裁剪，不按类别或接受像元数重采样。
- 每臂固定 **1000个尝试步骤**，batch1、float32；AdamW lr=1e-4、weight_decay=0.01、betas=(0.9,0.999)、eps=1e-8，恒定学习率；优化器仅接收新增模块参数。
- 对接受像元计算三父类CE；学生Cloud logit为Thick/Thin的logsumexp。归一化分母为该步接受像元数。
- 全ignore裁剪跳过前向、反传和optimizer.step，记录原因；不补步、不只做weight decay。报告实际更新数。
- 保存初始和第1000尝试步末状态；只评价固定末步，不早停、不选最低训练损失checkpoint。
- 固定探针：按product ID排序的前4个fit产品，取中心512裁剪。在第0/100/500/1000尝试步，各臂每裁剪前向一次，保存三类预测及相对固定教师变化率，共32次学生前向。探针不参与训练或选模，预测比例不当作正确率。
- 两臂末步及SHA封存后，独立本地评价程序在这4个固定裁剪连接真值，统计教师错误被学生修正/恶化的计数。训练进程不读取这些审计标签，审计结果不回流本轮。

### 4．实现验收和固定评价

- 关闭模块时复现原R4，raw输出最大误差<=1e-5；开启时新增路径有有限梯度、原参数无梯度；原参数/BN/buffer初末一致。验收反传后恢复新增模块初始状态、清梯度和随机状态。
- 检查四到三类映射、0.90边界、全ignore跳步、两臂伪标签/裁剪SHA一致。教师完整滑窗拼接须复现原实现，不能用其他后处理替代。
- 原R4/E4评价缓存核验身份、共同支持和SHA后复用；只新增B-PL/M-PL在Catalogue32组和PixBox16产品的预测。保存连续Shadow分数、四类argmax、三父类预测，避免后补前向。
- 决策沿用官方四类raw argmax后合并Thick/Thin Cloud。评价AP使用原官方Shadow分数口径；训练概率与评价分数分别保存定义。不使用53组旧阈值，不为主表选择新阈值；下述oracle只作独立诊断。
- 主要指标为Catalogue **逐相关组平均三类mIoU**；并报池化mIoU、各类IoU、Shadow宏/池化AP、宏召回、宏误报。缺类规则复用Phase208实际实现并写入表注；无影组仍参与mIoU和误报评价。PixBox仅报参考点指标，不计算全景mIoU/FPR。
- 独立CPU复核混淆、AP、组均值和池化值。Catalogue主要三项比较见表二；按32相关组配对bootstrap10000次、seed300020，每次重算组均及池化混淆指标。区间只描述固定单seed模型，不把像元当独立样本。

### 5．检查三类云特有偏移

仅在两个末步封存后，使用现有元数据、标签说明及已有评价预测填写表五，不增加训练或下载，不按模型结果挑子组。

- **云/云影与地表混淆：** 分开统计真值Surface被判Cloud、真值Surface被判Shadow，以及真值Cloud/Shadow被判Surface。若PixBox已有可靠地表类型字段，按其原始定义列亮地表及暗地表子类，提交字段到类别的固定映射；缺字段则填缺项。不能将预测亮度或误报样例自行命名为雪、盐湖、水体，也不能仅凭全池误报下降认定修复了特定地表混淆。
- **跨传感器波段不一致：** 列本轮实际sensor、波段及分辨率。若两评价池均为Sentinel-2，则明确“本轮没有跨传感器验证”；B08/B8A替换和重采样差异单列，不能当作跨传感器。仅交现有输入差异清单，本轮不追加传感器实验。
- **标注口径偏移：** 对照Catalogue/PixBox原始类别、Thin/Thick合并、Cloud Shadow、地形阴影和ignore定义，写出共同父类映射及仍不可比之处。缺少原始细类时不估计薄云/边界指标，不用教师预测补真值。不同标签源上的性能差异不直接归因于标注偏移。

上述三项是候选解释，本轮只报告可用支持、对应误差及缺口；不同时加入三个新模块。

### 6．区分工作点变化与排序改善

复用R4、B-PL、M-PL评价缓存，做一次CPU oracle诊断。对每池、每个学生，取其默认云影决策的**全组等权平均负类误报比例**为预算；在该池R4连续Shadow分数上选择满足预算的最低可行全局阈值，报告R4实际达到的误报和召回，再与学生默认决策比较。

阈值并列分数整批纳入/排除，不按景单独选阈值、不插值伪造相同误报。误报预算包含全部组，召回仅平均有正参考组。记录目标预算与实际误报差；无可比支持时填NA。仅填表六，不给扫描结果做额外显著性声明，不产生部署阈值，不回流训练或checkpoint选择。

同时报告学生−R4的AP差及教师/学生纠错计数。若默认误报降低，但AP及匹配误报召回没有明确改善，写“变化主要与工作点移动相容”；有剩余收益则写出所在池、幅度和代价。二者都不等于已证明内部机制或云特有偏移被解决。
