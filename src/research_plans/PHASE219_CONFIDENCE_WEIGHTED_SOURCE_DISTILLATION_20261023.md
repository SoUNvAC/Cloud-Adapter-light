## 3．唯一新增公式

使用Phase218同一语义聚合，冻结教师eval：

```text
p = softmax(S_Source, class, T=1)                 # FP32、detach
q = softmax(S_student, class, T=1)
k_i = sum_class p_i * (log p_i - log q_i)
c_i = max_class p_i

对每张源图的原共同几何支持，按c_i从高到低稳定排序：
恰好一半像元权重1.5，其余0.5；相等时按行优先索引升序。
L_G = mean_i(w_i * k_i)
L_S = mean_i(shuffle(w)_i * k_i)
总loss = 原目标监督loss + 1 * L_G或L_S
```

512×512无padding时，两种权重各131072个，每图平均权重严格为1。若实际有效几何不符原协议，先排查，不擅自改变支持。权重不依赖学生预测、参考标签或已知受损ROI；不使用教师argmax类别分组。

S打乱索引由`SHA256('phase219|' + 官方source_sample_id)`前8字节按大端无符号整数生成局部PCG64种子，再对行优先权重向量做一次permutation；使用锁定NumPy版本。每图固定一份打乱，两个seed共用，重复回放不重抽。封存每图G／S权重SHA和随机索引SHA。不得调用全局RNG。

G／S每图权重直方图、均值完全相同，消除总权重变化；**不保证两臂KL值或梯度范数相同**。记录未加权KL、加权KL、目标loss、高低权重区KL及实际梯度有限性，不据loss差临时重标定λ。教师semantic-softmax置信度不是校准正确概率。

门检零更新：初始头一致、初始KL近0、权重不参与梯度、源梯度只到head、S保持权重直方图、教师和非head不变。再用固定小数组核验显式逐像元公式；门检后恢复初始化／优化器／RNG。

α=1额外流式统计Phase218四种“教师／学生参考正确性”状态，107 ROI全部保留。对每个候选相对D，输出：

```text
保住教师正确的净收益 = D(教师对/学生错) - 候选(教师对/学生错)
失去教师纠错的净代价 = D(教师错/学生对) - 候选(教师错/学生对)
候选−D错误像元 = 净代价 - 净收益
```

负代价表示恢复了更多纠错。上述是固定教师正确／错误区域内的净计数，不冒充D→候选逐像元直接转移，不用于分解非线性mIoU或证明梯度因果。

同次教师输出中，在源val按相同置信度规则分高低两半，报告每半的参考错误率及三类支持；只作诊断，不能据此改训练权重。Replay不读标签，不报告准确率。四个历史焦点0050／1013／1404／4813另列，但不替代全107 ROI结论。
