# Phase95：固定模型的校准尺度诊断

## 做什么

检查Catalogue的20m校准与ALCD的60m概率聚合是否造成工作点偏移。**零模型拟合、零网络前向、零下载；仅新增四个阈值。**本轮为探索诊断，不设模型晋级、不直接选部署方案。

## 1．固定输入

- 复用Phase94的`G7_100.pkl`、`SourceS_100.json`、原100／53组划分及输入锁，先核验SHA。两模型均不重新拟合，标准化不变。
- 校准只用原53个留出组的完整有效分数、参考标签与掩膜。复用缓存；允许运行已冻结的浅层评分器，禁止补跑Source网络。
- 评价池固定为32个development代表、ALCD原版9组及原版／修订版6组共同支持。旧sealed不读取。

## 2．构造同区域的20m／60m校准支持

对每个Catalogue校准场景执行一次固定处理：

1. 原1022×1022数组从右边、下边各裁2像元，保留左上原点的1020×1020，分成不重叠3×3块。不得搜索偏移或窗口。这是**数组上的合成60m格网**，不宣称已核验与ALCD原生格网对齐。
2. 仅保留9个像元均满足既有有效掩膜、且三类参考标签完全相同的块；混合块与无效块排除，不采用多数票。保存每组各类保留量及保留比例。
3. `20m_same`使用这些块内全部9个原始分数；`60m_same`使用同一块内9个**云影概率的算术均值**，粗标签取其共同标签。负类始终为Surface＋Cloud。
4. 先逐像元评分，再平均概率；不得平均logit、波段或先平均输入再评分。SourceS沿用原logit→sigmoid流程；G7输出已经是概率，不能再做sigmoid。

两种新校准支持覆盖同一物理区域，每块恒有9像元。若某组无有效负类，记录未定义；两种校准同步排除该组并报告实际组数，不填0或补组。

## 3．每模型固定三个阈值

| 阈值 | 校准方式 | 用途 |
|---|---|---|
| T20_full | 原Phase94的T_cal，直接复用 | 原始基线 |
| T20_same | 53组的20m_same | 排除裁边／标签同质筛选影响的对照 |
| T60_same | 53组的60m_same | 聚合尺度对照 |

两个新阈值均按**逐组等权平均FPR≤1%**的原保守exact-ties规则选择最低有效阈值，不用抽样近似。禁止搜索其他预算或根据评价结果追加校准。

- T20_same：G7沿用float32概率；SourceS沿用float32 logit，并保存对应概率阈值。
- T60_same：概率均值及阈值使用float64。阈值搜索、并列分组和最终比较保持同一精度；检查旧工具是否会静默转成float32。
- 比较均用`score >= threshold`。保存阈值域、概率阈值、组权、实际校准FPR及下一较低候选的FPR。
- **四个新阈值全部落锁后，才运行新的development／ALCD评价。**不在ALCD标签上定阈值。

## 4．评价与报告

共六行策略：两个模型各配三个阈值。主要比较为同一G7的`T60_same−T20_same`；SourceS做同样对照。`T20_same−T20_full`单列，不能归为纯聚合影响。

1. **ALCD：**完全沿用Phase94的60m概率聚合、有效掩膜和双版本共同支持。报告宏召回、宏FPR及单侧95%上界、精确率、Shadow IoU、超1%组数、最大单组FPR和逐组变化。
2. **Development：**按第2节同样构造合成60m同质支持，三个阈值均在这份相同支持上评价。报告支持损失、实际有云影组数及上述指标；不得与Phase94的原20m指标直接相减解释。
3. ALCD每模型的三策略分数、宏／池化AP必须完全一致；development每模型在本轮固定支持上的AP也必须一致。阈值变化不能称为排序恢复。
4. 配对相关组bootstrap 10000次，seed95012；FPR用所有有负类组，召回用有参考云影组。给差值双侧95%描述区间及FPR单侧95%上界，不能按像元bootstrap。

本轮只能描述尺度与支持筛选的影响。合成同质块偏向类别内部，不能代表全部真实60m混合像元；匹配聚合算子也不消除跨域差异。ALCD已被查看，结果不能作为新的独立确认。平均预算通过不代表每景通过。

缓存缺失或身份／数值链路不一致时停止并报告，不自行补训练或网络推理。不追加格网偏移、同质规则、保守预算或第二轮阈值。人工裁决与恢复缓存谱系局限继续披露。
