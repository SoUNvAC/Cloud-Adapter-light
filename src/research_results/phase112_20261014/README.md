## 2．结论分析

**未取得G7相对Omni的排序增量；观察到的方向相反。** 同一支持上Omni的宏AP和池化AP更高，8个有云影组的AP均高于G7。这说明后续方法应正视这个固定强基线，不能仅凭较弱Source或低容量光谱读出对照宣称竞争力。

这仍是已暴露PixBox池上的探索描述，不能把反向差值改成新的预注册成功终点，也不能称独立确认或严格论文复现。V1训练位置交集未知、选择性采样、参考语义及旧池暴露限制保留。Omni confidence经过作者截断与偏移，并非校准正确概率。

工作点结果提供实际决策背景，但没有全景FPR、1%预算保证、尾部安全或三类mIoU结论；Omni仍有低召回组及无参考云影组误报。未换权重、波段、窗口、支持、主要比较或阈值，也未据结果追加模型／候选／校准。
