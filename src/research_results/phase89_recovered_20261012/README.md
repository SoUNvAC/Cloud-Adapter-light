## 2．结论分析

原版主要增量的描述区间在零以上，支持与该公开参考的一致性增益；不能升级为标签验真或正式确认通过。
同一支持下两版平均增量均正，只能描述方向一致；不据此确定哪版是真值。
L3在本池原版主分析的实际平均误报率超过1%预算；阈值保持冻结，不在外部池重校准。

九组是统计单位，像元和块数不会增加独立样本量。人工与参考不一致不等于标签错误，也不估计全景正确率。此前质量抽查暴露及标签未完全裁决的限制仍在；项目内空间排除不代表已知基础模型全部预训练地理谱系。
不修改参考、成员、mask、候选或阈值，不恢复旧主检验，不宣称TGRS方法成立。
