# Phase88：57点人工盲审包

## 从这里开始

打开[index.html](index.html)。你已选择担任主审，请先填写姓名或可追溯编号及遥感判读经验说明。页面逐点显示小、大窗口，点击图片可以放大并横向滚动；先看中心红框，再填写判断、依据、窗口是否足够，以及是否需要晴空日期或DEM。无法判定是有效答案，不必强行选择云影。

中途用“导出草稿JSON”保存进度；回到页面可导入草稿继续。浏览器缓存不是交付文件。全部填完后点“导出完整A阶段JSON”，**交回expert_A.json**，不要只保存网页。

执行者验证57点填写完整、保存原文件并锁SHA后，才生成单独的stage_B.html。B阶段对照两版参考，填写expert_B_template.csv并交回：未发现明确冲突／有证据支持可能冲突／仍无法裁决，并给出理由。A结果不能覆盖，参考版本均不自动是真值。

本轮不要求逐像元描图。大窗口增加地物上下文，没有提高60米标签分辨率；边界点只显示真实支持，不镜像补图。需要外部影像或DEM时只登记，本轮不下载。

为保留盲判，请判读前只使用index.html和匿名images文件，不查看抽样身份锁、此前AI结果或标签图。窗口NPZ不含标签类别，但身份锁属于协调资料。

## 2．结论探讨

当前完成的是专家可使用的材料准备，人工盲判与裁决尚未执行，因此尚不能判断人工证据是否足以支持下一步参考一致性评价。确认就绪组数仍为0，不能把材料准备称为专家复核通过。

定向抽查不估计全景准确率；57点不等于57个独立场景。即使完成裁决，后续外部评价仍须先冻结参考政策、有效mask、尺度、模型与终点。本轮没有训练、分割推理、新下载或标签修改。

## 文件与锁

- index.html、images：匿名逐点盲审页及可放大小／大窗口。
- expert_A_template.csv、expert_B_template.csv：空白人工模板；网页导出的expert_A.json是推荐A阶段交付。
- sample_input_lock.json、SAMPLING_FROZEN.json：先冻结的成员、抽样身份、原输入SHA；不用于盲判。
- extraction_audit.json、windows：新提取六波段与60米joint-valid mask、原像素一致性检查及坐标；NPZ不包含参考标签类别。
- metric_display_audit.json、images/*_context.png：最终大窗口保持真实长宽比，9个边缘窗口不补地物。首版方形预览和layout_v1.html仅留作排版过程记录，请使用index.html开展判读。
- evidence_needs.csv、group_status.csv：证据需求与分层待执行状态。
- LOCAL_VERIFIED.json、DELIVERY_SHA256.json：完成后的实际校验与交付哈希。
