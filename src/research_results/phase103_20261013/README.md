## 2．结论与限制

得到的是本任务保守二分类定义下的发布参考支持，不是新人工核验真值，不是完整复刻CMIX。官方定义C=1为None、C=7为Clear；C=1按用户预定的云属性缺席解释，单独报告。已取得的官方说明及CMIX公开说明未发现实质冲突，但可执行CMIX逐码映射未完整独立验证，见semantic_basis.json。本批有效支持均来自显式C=7，不代表未来可取消该语义限制。

8组满足“至少一正一负”的AP可计算条件，仅是数学支持，不代表最低组数、区间宽度或独立确认支持已达标。没有计算AP、召回、FPR或mIoU，没有载入模型输出，也没有选择模型、代表或有利子集。19GBQ／48NUG保留在固定池，AP不填0，不追加产品补正类。

## 标签访问及文件边界

本轮已读取16产品的逐点类别，不能再称“标签未读取”。原ZIP物理上包含全部29产品；先只解析行首ID／产品链接，白名单外7851行的类别部分保持不透明、不解码成字段、不统计类别。原ZIP的解压流仍经过这些字节，不能声称未取得或未接触包含排除行的文件。

本轮原始及派生逐点表仅在本地受控目录`data/pixbox_s2_cmix_5036991/phase103_20261013/`，不进git、不传远端。Phase102既有原ZIP历史副本原样保留，不改旧来源锁。受控目录包含白名单原行、完整原属性与原因、重复冲突记录及每个20m单元的点数／标签组合／冲突，SHA列于support_report.json。没有标签与work_dirs同步。

本交付仅包含规则、成员锁、哈希、每产品／每组聚合支持、聚合重复／位置冲突表和CPU回执：

- reference_mapping.json、prelabel_lock.json、READY_BEFORE_LABEL_ACCESS.json：读取前规则与时间顺序证据。
- per_product_support.csv、per_group_support.csv：全部16产品／10组，含C1/C7、各ignore原因及聚集程度。
- duplicates_and_position_conflicts.csv：每产品聚合重复、位置pending和20m冲突计数；逐位置细表留受控目录。
- CPU_INDEPENDENT_VERIFIED.json：用另一套显式真值表逐行复核9500行、全类别属性重复、组／产品计数、C1/C7及9484个20m单元；不调用主分类函数，不计算性能。
- INPUT_READINESS.md：只回答参考支持与下一轮输入核验是否值得开展。

未知抽样包含概率仍不能估全场景平均／尾部FPR或密集mIoU。Source基础预训练独立性未知；不设新校准池、不改旧锁和失败，Kappa保持pending，预算截止2026-10-20北京时间。
