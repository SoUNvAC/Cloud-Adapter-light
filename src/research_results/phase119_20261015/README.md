## 2．结论探讨

本轮显示的是精度、显存和推理计算的取舍，尚不能用一个单模型全面替代集成。R在PixBox的组平均AP高于E，但在Catalogue development明显落后；N在Catalogue更接近E，在PixBox则下降。两池分别评价，不能平均两个宏AP或挑有利池宣布胜出。

R−E在PixBox为+3.198pp，描述区间[−6.142,+13.800]，2组改善／3组稳定／3组下降。均值主要由22WES的+20.257pp和44SKJ的+31.083pp拉高；54TWN下降20.554pp，且只有7个参考云影点。池化AP83.615%与E的83.645%接近，没有同步出现宏AP同幅收益。固定0.5下，R的组平均召回由71.969%升至77.317%，所选负类误报也从1.125%增至1.883%。这些数据支持保留R的局部能力线索，不支持“R已普遍优于集成”。

R在Catalogue的宏AP比E低3.378pp，区间[−5.536,−1.421]，7个有影组中6组下降、1组稳定；32TML和38TNN分别下降8.148pp、7.699pp。其组平均召回更低、负类误报更高，因此不能把损失仅解释为较保守的决策阈值。N−E宏AP为−0.615pp，区间[−1.886,+0.796]，1改善／4稳定／2下降；N的组平均负类误报低于E，但这并非等效证明。N在PixBox下降3.853pp，区间[−6.940,−0.850]，5组下降，也不能作为两池通用替代。

成本上，R只有18.039M参数、72.315MB权重，E为50.574M、202.480MB。相同三景六次运行，R的GPU模型计算15.122秒，为E的36.4%；N为27.981秒，约67.3%。GPU观测峰值E／R／N约10.195／4.325／7.903GB，R有更明显的计算和显存优势。但扣除额外CPU检查后的整景估计分别358.514／334.106／345.100秒，R和N仍约为E的93.2%和96.3%。非模型环节占主要时间；本轮没有将它进一步拆分，不能把剩余耗时全归因于磁盘。带验收钩子、CPU预取重叠和系统缓存也限制了这些整景差值的解释，不宣称普适加速倍数。

优先保留R作为“小模型恢复”候选，理由是实测资源节省较大，且PixBox并非全面丢失能力；Catalogue损伤则明确指出需要恢复的部分。这是下一步研究选择，不是部署通过结论。只建议NEXT_STEP.md中的一项固定小试验，不再围绕当前结果同时增加特征、阈值或多个训练方案。

统计仍仅有PixBox的8个、Catalogue的7个有影相关组，后者数千万像元不增加独立样本数。数据池已经暴露，参考语义和训练地点交集限制保留；池间反转不能未经分层就归因于某种地表、云影类型或标签质量。本轮只做单成员消融，尚不是新算法贡献，也不改写历史失败或正式确认结论。

## 3．下一小步

只建议一次固定预算的E→R蒸馏恢复试验：以冻结集成E为教师，原RegNet单模型R为学生，在原fit拟合、development评价，保留未修改的R／E／N作对照。目标是补回R在Catalogue的排序损伤，并保留其计算与显存优势。

下一协议应先固定蒸馏目标、训练步数与候选规则；不同时搜索新波段、窗口、阈值和多个损失配方。PixBox不参与拟合、调参或checkpoint选择；当前R在其部分组的优势未必能在模仿E后保留，须完整报告损伤，不能预先承诺两池都改善。

这是基于本轮取舍的一项提案。本轮未读取fit像元、未开始蒸馏或其他训练，需后续明确授权与资源协议后执行。

## 4．验收与边界

实际累计模型调用3470，推理任务保守wall 2871.301秒；含构建、预热和所有完整重复，明细在COST_SUMMARY.json及各worker回执。宿主物理盘余量13.344GB，打包前新增中间文件1324621471bytes。

E三景旧分数复现、各设置整幅重复、独立CPU raw平均／拼接／取点confidence误差均≤1e−5，覆盖与gradient一致；Catalogue还用真实R／N原始logit重建E核对旧缓存，没有从集成confidence反推单模型。两池先封存全部分数和共同支持，再分别连接原参考，独立并列AP与标量组bootstrap验收通过，旧E基线重新计算复现。

本轮未评价153个fit组，未自动启动训练或下一实验。原影像、权重、参考与历史失败不改写；无work_dirs打包／同步／清理。Catalogue密集分数和raw logits留远端shared，PixBox逐点分数及原参考连接留本地受控data，不入Git。仅代码、小聚合结果与SHA按push／pull交付。

两池已经暴露，训练地点交集与参考语义限制保留；这是固定单成员消融和成本对照，不能单独宣称新算法贡献、独立外部确认、全景安全性或跨硬件加速保证。最迟2026-10-20北京时间停止线保持。
