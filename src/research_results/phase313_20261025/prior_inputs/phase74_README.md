## 2 结论探讨

执行前锁定的继续研究条件：

- E拟合版全组宏FPR低于B：未满足。
- E拟合版相对B宏召回损失不超过1个百分点：满足。
- E拟合版宏AP不低于B：满足。
- E拟合版宏AP高于R拟合版：满足。
- E拟合版全组宏FPR不高于R拟合版：未满足。

E拟合版相对R拟合版的宏AP差为+0.513 [-1.707, +2.939]个百分点，区间跨零，不能把正点估计解释成稳定排序增益；改善/稳定/下降为3/2/2组。
固定参数排除E相对B：宏FPR差-0.156、宏召回差-3.340个百分点。它降低误报也损失召回；公平重拟合后召回回升，但E拟合版的FPR高于B和R拟合版，未形成预设的恢复收益组合。
E拟合版全组宏FPR点估计为0.889%，低于1%；单侧95%上界为1.467%，高于1%，因此预算稳定性仍不确定。

预设联合条件未全部满足，停止本轮预测云邻居排除分枝；不从固定参数版中挑一个好结果替代失败拟合版，不继续搜索窗口、排除阈值或回退数量。此结论不表示全部空间信息无用。

E是Source预测，可能误识别真实云影；R仅匹配全景数量，空间分布和局部邻居数不同，因此E−R差不能单独证明光谱云污染因果。只有7个有云影development组，区间及逐组损伤须完整保留。旧H1支持门、Phase72失败结论与地形分枝not_ready均保持。
