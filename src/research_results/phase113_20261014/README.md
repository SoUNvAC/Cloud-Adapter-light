## 2．结论分析

**未找到达到固定判据的Source_spectral补充排序线索，按协议关闭本组既有补充评分假说。** 在Omni粗分箱内，Source_spectral不仅没有超过Omni，平均条件AUC还低11.132个百分点。32SPJ、19FDV、44SKJ有小幅正差，不能替代总体主要诊断；不因此追加单景定制、分箱、特征或融合拟合。

错误流显示局部检出差异，但伴随额外负类误报与原已检出云影的损失。它不证明任何融合能改善，也不证明所有可能的新信息都无用；关闭范围仅为这组固定既有评分与本次诊断。

固定粗分箱不等于严格条件独立或因果控制，箱内排序也不等于整体AP。PixBox已经暴露，区间是事后描述；选择性点样本、参考语义和未知训练位置交集限制保留，不声称全景FPR／尾部安全或独立验证。Phase112的G7强基线增量失败继续关闭；Phase105的有限条件增量事实保留，但不据此声称方法优于成熟强基线。
